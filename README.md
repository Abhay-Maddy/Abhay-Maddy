#### 🌐 Language-Translator

<img src="https://github-readme-stats.vercel.app/api/pin/?username=Abhay-Maddy&repo=Language-Translator&theme=nord&border_color=7dd3fc&title_color=7dd3fc&icon_color=7dd3fc" alt="Language-Translator pin"/>
